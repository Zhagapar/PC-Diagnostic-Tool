# PC Diagnostic Tool

Простая Windows-программа для просмотра характеристик компьютера и проверки свободного места на дисках.

## Возможности

- Отображение информации об операционной системе.
- Просмотр сведений о процессоре.
- Отображение оперативной памяти.
- Проверка дисков: общий объём и свободное место.
- Цветовые индикаторы заполнения дисков.
- Предупреждения при высокой загрузке диска.
- Обновление информации.
- Сохранение отчёта в текстовый файл.
- Графический интерфейс на Tkinter.

## Технологии

- Python
- Tkinter
- psutil
- PyInstaller

## Запуск из исходного кода

1. Установите Python 3.
2. Установите необходимые зависимости, если они используются в проекте.
3. Запустите команду:

```bash
python pc_diagnostic_v3.py
```

## Сборка EXE

Для создания исполняемого файла Windows используется PyInstaller:

```bash
python -m PyInstaller --onefile --windowed --name PC_Diagnostic_Tool pc_diagnostic_v3.py
```

Готовый файл появится в папке `dist`.
